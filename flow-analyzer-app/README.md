# هندسة التدفق — دليل النشر

هاد المشروع فيه ملفين أساسيين:
- `index.html` — الواجهة يلي بيشوفها عملاؤك ويرفعوا فيها الصور
- `api/analyze.js` — الجزء يلي بيتواصل مع خدمة التحليل بشكل آمن (مفتاحك ما بينكشف)

## خطوات النشر (مرة وحدة بس، ياخدوا ٢٠-٣٠ دقيقة)

**1. جهزي مفتاح API**
روحي لـ console.anthropic.com، اعملي حساب، وشحني رصيد بسيط (البداية بضل بدولارات قليلة). من "API Keys" اعملي مفتاح جديد واحفظيه بمكان آمن — رح تحتاجيه بخطوة ٤.

**2. ارفعي المشروع على GitHub**
اعملي حساب مجاني على github.com، اعملي مستودع (repository) جديد، وارفعيله هالتلات ملفات (فولدر api لازم يضل فولدر جوا المشروع مش يتفرط).

**3. اربطي المشروع بـ Vercel**
سجلي دخول على vercel.com بحساب الـ GitHub تبعك، دوسي "Add New Project"، واختاري المستودع يلي رفعتيه.

**4. ضيفي مفتاح الـ API (خطوة مهمة جداً)**
قبل ما تدوسي Deploy، رح تلاقي قسم "Environment Variables". ضيفي متغير:
- الاسم: `ANTHROPIC_API_KEY`
- القيمة: المفتاح يلي جهزتيه بخطوة ١

**5. Deploy**
دوسي Deploy. بعد دقيقة أو دقيقتين رح ياخد رابط جاهز شكله متل:
`https://your-app-name.vercel.app`

هاد الرابط هو يلي بتشاركيه مع عملائك أو تحطيه بموقعك/بايو الانستغرام.

## ملاحظات
- كل تحليل بياخد جزء بسيط من رصيد الـ API (أقل من سنت للتحليل الواحد تقريباً).
- لو حابة تغيري النص أو الأسئلة يلي بيسألها التطبيق، الكل موجود بملف `index.html`.
- لو حابة تغيري شخصية التحليل أو أسلوبه، عدلي على النص جوا `api/analyze.js` (الجزء المسمى systemPrompt).
- لو ما بدك تتعاملي مع هالخطوات بنفسك، أي مبرمج فريلانسر بيقدر يعمل هاي النشرة بأقل من ساعة شغل.
